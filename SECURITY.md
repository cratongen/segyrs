# Security

## Supported versions

The latest release is the supported version.

## Reporting a vulnerability

Report a vulnerability in private at
<https://github.com/cratongen/segyrs/security/advisories/new>.

Do not open a public issue for a vulnerability. Do not describe it in a
pull request or on another public channel.

## What to include

- The segyrs version, or the commit you tested.
- What you expected, and what happened.
- The steps that show the problem. Use a file you may share. Do not attach
  a SEG-Y file you may not share.
- The effect you observed.

## What to expect

A maintainer replies on the advisory. A confirmed vulnerability is fixed in
a release. The advisory stays private until that release is published.
